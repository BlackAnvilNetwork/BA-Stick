# Black Anvil lore

Design canon for the world. These files are for writers and builders, not players. Players see only the spoiler-safe wiki pages.

- [lore-bible.md](lore-bible.md): the canon. History, the Seven Seats, regions, people, the fragment trail, naming rules.
- [player-wiki-lore.md](player-wiki-lore.md): the spoiler-safe text the in-game wiki draws from.
- [civilization-layer.md](civilization-layer.md): places of interest, "The Seven Hands" story trail, and Mayflower's districts.
- [regions-and-peoples.md](regions-and-peoples.md): each region's land, peoples and routes.
- [continent-geography.md](continent-geography.md): the continent's shape and how the areas connect.
- [seam-country-population.md](seam-country-population.md): Seam Country's creatures, camps and quests.
- [grounded-notes.md](grounded-notes.md): review notes that check the lore against the actual terrain.
- [final-reveal-notes.md](final-reveal-notes.md): the endgame reveal. Spoilers.

Forest Basin is being rebuilt from a blank map. Its places in these files (the Counting Ring, the Drowned Spoke, West Ridge Top, High Ridge Corner, the Sealed Pass Shrine) describe the earlier design and aren't in the game right now.

Reference images (heraldry guide, warp circle, periodic table) aren't committed here because each is 2 to 4 MB.
