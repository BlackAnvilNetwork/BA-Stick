- [regions-and-peoples.md](regions-and-peoples.md): each region's land, peoples and routes.
- [continent-geography.md](continent-geography.md): the continent's shape and how the areas connect.
- [seam-country-population.md](seam-country-population.md): Seam Country's creatures, camps and quests.
- [grounded-notes.md](grounded-notes.md): review notes that check the lore against the actual terrain.
