# Knight — shipped slice

**Feel:** Slow, loud, shield-forward; hate tools first.  
**Seed:** `bellgrave-93471-knight` — steel / charcoal / crimson / pale-gold divine.

## Play

1. Claim starter (or already have TIM).  
2. Job Master → **Knight** (grants Iron Sword + Iron Mail if missing).  
3. Hotbar: Provoke, Flash, Shield Bash, Bulwark… — Rest pinned.  
4. Spells unlock by level (no trainer). Use K for the book.

## Kit

- **JAs:** Bulwark (2HR phys immune), Provoke, Shield Bash, Cover, Rampart, Sentinel, Fealty, Chivalry, Guardian  
- **Divine:** Cure I–IV, Banish/II, Protect I–III, Shell I–III, Flash, Holy  
- **VFX:** Silver/crimson bulwark tint (not TIM teal orbs)
